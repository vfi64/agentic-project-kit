Repository-owned governance for AI-assisted work

Agentic Project Kit

Design and deliver software with AI agents, without having to be a programmer or a GitHub specialist.

Not a coding assistant and not a replacement for Cursor, Claude Code or Codex: the control layer above them. You decide; agents write the code; the Kit keeps rules, decisions and memory in your repository and handles the GitHub mechanics.

Works best with Codex CLI or Claude Code. File Transfer with a browser chat saves API and CLI costs; Copy and Paste is the emergency path.

Quickstart Use with Codex or Claude

Two sessions, one repository

Continue a reviewed change in a new chat

Imagine a small Python CSV exporter. You ask an assistant to add tab-separated output while preserving comma-separated output. The assistant proposes code and a regression test. You review both and run the tests and configured Kit checks.

Record the current goal, test results and next step in the repository. Generate the validated successor package and give the next session access to it so the assistant can resume. A failing CSV regression test reports a break only if the test covers that behavior.

You decide whether the change meets the requirement and whether to approve a merge or release. The Kit's green checks confirm only their named conditions.

Who it serves

Maintainers of continuing projects

Solo maintainers and small teams working with AI on Git-backed software or documentation, particularly across long sessions, reviews and releases. Python is a reference profile; equal maturity across all toolchains is not claimed.

Why use it

Durable context and bounded actions

Repository state replaces dependence on chat memory. Manifest-backed workflows expose effects, checks and evidence. Generated handoffs make the next session inspectable.

Mechanisms and tradeoffs

What it costs

Explicit process takes work

Adoption requires Git knowledge, maintained contracts, useful tests and review. More state files and closeout steps are real overhead. Green gates do not prove correct requirements or defect-free software.

Read the limits

Why

Repository memory

Long LLM projects lose time when context lives in chat history. The Kit makes the repository the durable project memory: current state, handoff packages, command manifests, gates, reports and release evidence are inspectable before new work starts.

Install

Start locally

python -m pip install agentic-project-kit

PyPI publication workflow evidence for this version is unverified. Git is still a system prerequisite for agentic-kit init and Git-backed workflows; pip cannot install Git portably. After installation, run agentic-kit --version, then choose agentic-kit init for a new governed repository or agentic-kit workspace adopt for an existing one.
