An everyday use case

Continue tomorrow without rebuilding the project context

You discuss a change in a browser chat. The Kit prepares repository context and a bounded next step. You run the local workflow; it records check results and the remaining work. When you change chats or assistants, a generated handoff carries the repository state forward.

You can also use a local coding agent or controller. An autonomous multi-agent framework, paid agent platform or LLM API is not a prerequisite. Git, a local Kit installation and the permissions required by your chosen workflow still matter.

The useful result is an inspectable work process: what was requested, what ran, what passed or failed, and what is next. Checks enforce defined rules; the maintainer still reviews whether the change solves the right problem.

Who it serves

Maintainers of continuing projects

Solo maintainers and small teams working with AI on Git-backed software or documentation, particularly across long sessions, reviews and releases. Python is a reference profile; equal maturity across all toolchains is not claimed.

Why use it

Durable context and bounded actions

Repository state replaces dependence on chat memory. Manifest-backed workflows expose effects, checks and evidence. Generated handoffs make the next session inspectable.

Mechanisms and tradeoffs

What it costs

Explicit process takes work

Adoption requires Git knowledge, maintained contracts, useful tests and review. More state files and closeout steps are real overhead. Green gates do not prove correct requirements or defect-free software.

Why

Repository Memory

Long LLM projects lose time when context lives in chat history. The Kit makes the repository the durable project memory: current state, handoff packages, command manifests, gates, reports and release evidence are inspectable before new work starts.

Install

Start Locally

python -m pip install agentic-project-kit

The public PyPI package is available. Git is still a system prerequisite for agentic-kit init and Git-backed workflows; pip cannot install Git portably. After installation, run agentic-kit --version, then choose agentic-kit init for a new governed repository or agentic-kit workspace adopt for an existing one.

Architecture

Runtime Structure

The Kit separates human decisions, replaceable executors, repository contracts, deterministic checks and external integrations. CLI, GUI and transport surfaces use governed core operations. A private local controller can transport and execute bounded work while the Kit owns its process contracts.

CLI

Normal Lifecycle

  • agentic-kit initCreate a governed project skeleton with selected profiles and policy packs.
  • agentic-kit workspace adoptAnalyze an existing repository without writing workspace files.
  • agentic-kit workspace initPlan or create a bounded operating-layer workspace.
  • agentic-kit workspace dpa-intakeRun the deterministic DPA repository-intake orchestration.
  • agentic-kit workspace upgradePlan or run deterministic workspace manifest schema upgrades.
  • agentic-kit work startStart a human patch/slice workflow with the safe standard startup sequence.
  • agentic-kit work recoverRun safe recovery/status commands after interrupted work.
  • agentic-kit work rescueRescue local main work before realigning main to the local base ref.

  • agentic-kit doctorRun a compact project health check.
