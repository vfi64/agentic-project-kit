When this route applies

Complete open pr

Phase: guarded. Required state: pr state = "open", workspace mode = "managed".

Required task inputs: expected_head_sha: full_commit, pr_number: positive_integer.

Pending CI is handled by the selected workflow; selection does not authorize its merge.
