agentic-kit release run

Run the governed end-to-end release orchestrator with resumable approval gates.

When this route applies

Release version

Phase: guarded. Required state: branch role = "main", release state = "none", workspace mode = "managed", worktree clean = true.

Required task inputs: version: stable_version.

Fresh release only; existing runs need a separate explicit resume/recovery intent. Without --execute the orchestrator still performs local A/B preparation; publication consent stays separate and version/tag/head-bound.
