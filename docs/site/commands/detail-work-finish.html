When this route applies

Finish work

Phase: planning. Required state: branch role = "work", workspace mode = "managed".

Required task inputs: branch: nonempty_string, message: nonempty_string, paths: nonempty_string_list, title: nonempty_string.

Whole-slice plan; an already open PR is a separate explicit intent, never inferred from closeout tags.

Options and arguments

--branch
Feature branch to finish.
Required: true · Default: None
--title
Pull request title.
Required: true · Default: None
--message
Commit message.
Required: true · Default: None
--body
Pull request body; mutually exclusive with --body-file.
Required: false · Default:
--body-file
UTF-8 pull request body file.
Required: false · Default: None
--release-note-category
Release-note category, for example Fixed; validated before any action.
Required: false · Default:
--path
Path to include in the commit. Repeatable.
Required: false · Default: None
--merge-method
PR merge method.
Required: false · Default: squash
--merge, --no-merge
Run the full PR, merge, and post-merge handoff closeout by default. Use --no-merge only for an explicitly review-only PR.
Required: false · Default: True
--dry-run, --execute
Plan by default. Use --execute to commit, push, and publish.
Required: false · Default: True
--ci-timeout-seconds
Maximum wait for the pull request's CI (KIT-GF-078: the Kit's own full CI takes more than 300 s).
Required: false · Default: 900
--json
Print machine-readable JSON.
Required: false · Default: False
