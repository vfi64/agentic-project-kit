Current architecture: a guest in your repository

The operating layer reserves .agentic/ for Kit state. The project retains its own code, toolchain and authority. Python is the Kit implementation language; target repositories are not limited to Python.

What the history cannot establish

Self-hosting and familiar consumer observations can find real defects, but are not independent held-out evaluations. Historical release and command counts are not measures of correctness, time saved or portability. No current drift rate or productivity benefit is inferred here.
