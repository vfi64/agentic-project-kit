## Confirmed defect and repair

The umbrella audit unconditionally used the Kit's required document set, fixed
version mesh, source order and complete class inventory. External warn-mode
lifecycle findings still carried FAIL severity. The external branch now lives in
`external_documentation_audit.py`; shared result types live in a small model module.
The CLI remains a thin adapter and adds a pure `--json` result with scope/status.

External manifest workspaces audit sentinel-declared documents/sections/budgets,
registry scope, their release version anchors, registered documents and canonical
facts. Optional registries accept the generated empty bootstrap schema, standard
classes and explicitly declared classes. Invalid paths, missing declared files,
duplicate registrations, invalid declarations and managed-fact/version drift
remain blockers. The Kit self-hosting audit retains its existing seven dimensions
and required files. Manifest-less legacy auditing retains its previous behavior.

Transfer-disabled workspaces do not require handoff artifacts. With transfer
enabled, existing handoff state and successor packages use the existing validators;
absence of a previous handoff is legitimate. Stored package PASS is not trusted.
External lifecycle warn converts findings to WARN; strict mode and explicit
`doc-lifecycle-audit --strict` keep enforcement, and off suppresses lifecycle findings.
The lifecycle reader resolves namespace registries, with a legacy fallback only
when the resolved registry is absent. No monolith grows with external audit logic.

The same slice closes the package-3 evidence-path issue: the release metadata
authority gate discovers evidence under workspace tmp/reports paths, including
the real release-prepare report directory and custom report roots. Content,
version and changed-path authority validation are unchanged.
