Before the next session, update docs/handoff/CURRENT_HANDOFF.md with the current goal, test results, and next step. Then use the starter prompt again. A project made with agentic-kit init currently uses this manual handoff; the automated successor package requires different workspace sources.

What these checks do not decide

The Kit does not choose TSV as a requirement, write the feature, or replace your review. A green check or doctor result covers its named rules. A CSV regression is caught only when a test asserts the old behavior and that test runs.
