What this does not establish

  • These are known scenarios that informed the fixes. This is not an independent held-out security evaluation.
  • The differing denominators are not general security percentages, and the result does not measure unknown fault detection.
  • The offline experiment exercised neither live GitHub/CI/release services nor real adversarial repository access.
  • One deterministic run per scenario does not establish performance across machines, cost savings or absence of false positives in other repositories.
  • The separate paid context pilot had invalid fault injection and contaminated reference history. It provides no confirmatory effectiveness or token-saving result; further runs remain deferred.
